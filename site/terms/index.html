What the estimate covers

The CLI reports a metadata-based plan and conservative space bounds. Filesystems and copy tools can allocate data differently, and readable metadata does not guarantee write permission. The tool does not execute its manifest.

Your responsibility

Review the source, destination, conflict policy, verdict, and manifest before running a separate file operation. Keep a tested backup of important data. The software is provided without warranty, as described in the MIT License.
