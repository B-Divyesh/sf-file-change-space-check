How it works

Plan one copy in three steps

1

Scan metadata

Read file names, sizes, allocated blocks, entry types, and destination free space.

2

Apply a conflict policy

Choose overwrite, skip, or keep-both for paths that already exist.

3

Check and export

Compare safe headroom with free space, then print a path-sorted JSON manifest.

Install

Install the CLI from source

Rust 1.85 or newer is required. The direct download is a Linux x86-64 binary.

Download for LinuxRead the source on GitHub
Install from sourcev0.1.0
$ git clone https://github.com/B-Divyesh/sf-file-change-space-check.git
$ cd sf-file-change-space-check
$ cargo install --path . --locked
$ fcsc --demo

Limits and privacy

Know what the plan does not cover

  • No transfer: the JSON manifest does not copy or delete files.
  • No permission promise: readable metadata does not prove a later copy can write.
  • Sparse range: allocation depends on the filesystem and the copy tool.
  • Local run: the CLI works without accounts or network access.
