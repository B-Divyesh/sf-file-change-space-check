Privacy, plainly.

File Change Space Check is designed not to need your data.

The CLI

The CLI runs locally. It reads filesystem metadata needed for your requested plan. It does not upload file names, paths, contents, manifests, or usage data. It has no telemetry and makes no network requests.

This website

The website uses no analytics, advertising, accounts, cookies, or remote fonts. Its policy simulator uses a built-in fictional fixture and does not accept local files. A service worker may cache public site assets on your device so the documentation and demo work offline; clearing site data removes that cache.

Contact

Questions or vulnerability reports can be opened in the project's public issue tracker. Do not include sensitive paths or file names.
