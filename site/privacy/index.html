How we handle data

The CLI and sample demo work without an account.

CLI data

The CLI reads filesystem metadata for the plan you request. It does not read regular file contents by default.

The CLI has no network or telemetry feature. It does not upload paths, file names, manifests, or usage data.

Website data

This site uses no analytics, advertising, accounts, cookies, remote fonts, or third-party runtime code.

The demo uses a fixed sample and accepts no local files. Its controls stay in memory and are not saved.

A service worker caches public site files for offline use. Clear this site's browser data to remove that cache.

Questions

Open a report in the public issue tracker. Do not include sensitive paths or file names.
